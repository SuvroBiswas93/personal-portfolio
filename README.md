# Personal Portfolio - Suvro Biswas

A modern and fully responsive **personal portfolio website** built with **React**, **Vite**, and **Tailwind CSS**, showcasing my skills, projects, and contact information.

🌐 **Live Website:** [https://suvro-biswas.netlify.app/](https://suvro-biswas.netlify.app/)

---

## Features

- **Responsive Hero Section** with animated background and typewriter effect.  
- **Skills Section** displaying technologies with icons and colors.  
- **Projects Section** highlighting my work and live links.  
- **Contact Form** integrated with **EmailJS** for direct messages.  
- Smooth **scroll animations** and modern UI interactions.  
- Fully mobile-friendly and optimized for performance.

---

## Tech Stack

- **Frontend:** React, Tailwind CSS, Vite  
- **Animations:** Framer Motion  
- **Forms:** React Hook Form, EmailJS  
- **Icons:** React Icons, Lucide React  

---

## Installation

```bash
# Clone the repository
git clone https://github.com/SuvroBiswas93/personal-portfolio.git

# Navigate to the project folder
cd personal-portfolio

# Install dependencies
npm install

# Run locally
npm run dev
